processing" (2020). No third-party source code, images or textures are included; the sample artwork and
all test images are generated by code in this repository.

Development only: Vite, TypeScript, Vitest, Playwright, ESLint, pngjs (MIT / Apache-2.0). The optional
export inspection script `scripts/inspect_exports.py` uses Pillow (MIT-CMU) and NumPy (BSD-3-Clause),
installed separately by whoever runs it; neither is bundled or shipped. The redesign adds no runtime
dependencies and no new fonts.
